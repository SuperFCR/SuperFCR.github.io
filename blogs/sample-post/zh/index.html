使用这份研究博客模板快速上手

这篇入门教程展示了学术主页与研究博客模板的内置能力。版式参考 Lil'Log[1]，所有文章均为自包含的静态 HTML 页面，内置浅色/深色主题、桌面端左侧手风琴目录、本地化字体以及自动规范校验。

概览#

将主页编译与长文博客解耦后，两边都可以独立维护。build.js 负责根据 JSON 配置生成中英文学术主页，而 blogs/ 下的文章目录则可自由嵌入自定义矢量插图、响应式表格、代码块和数学公式，互不干扰。

主页与博客构建管线#

运行 npm run build 时，脚本不仅会生成中英文主页并输出带内容哈希的 WebP 缩略图，还会自动解析 blogs/index.html 中的最新文章卡片并渲染到主页 Blog 栏目。

公式渲染与插图#

数学公式完全依托 assets/vendor/katex/ 中的本地 KaTeX 资源离线渲染，无需外链 CDN。例如行内速度场写法为 $v_\theta(x_t, t)$，块级公式如下：

$$\mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t,\,x_0,\,x_1} \left[ \left\| v_\theta(x_t, t) - (x_1 - x_0) \right\|_2^2 \right], \qquad x_t = (1 - t) x_0 + t x_1.$$
文件用途校验方式
config/data.json个人信息、论文与经历配置npm run build
blogs/<slug>/index.html静态中英文文章页面blogs/check.py
blogs/index.html文章列表页与主页文章流来源blogs/check.py

发布流程#

复制 blogs/example/ 为新文章目录，在 blogs/index.html 登记条目后，推送前在本地依次完成校验与预览即可：

python3 blogs/check.py
npm run build
python3 -I -m http.server 8000 --bind 127.0.0.1
