这是一篇示例文章，用来检查 blog 的排版。整体结构参考 Lil'Log[1]：顶部导航、单栏正文、可折叠目录，文末附引用格式和参考文献。配色、背景和站名字体沿用主页。每篇文章都有英文版和中文版，用标题上方的胶囊切换。

段落与强调#

正文宽度约 900px，与主页同宽，中文行高 1.85。英文单词如 diffusion model 和数字 2026 使用 Inter，汉字使用苹方或微软雅黑。加粗用于关键结论，链接带一条细下划线，行内代码写作 flow_grpo.step()。

一段话尽量只讲一件事。读论文的笔记通常按“这篇做了什么、为什么有效、哪里还不够”的顺序写，读者扫一眼章节标题就能抓住结构。

列表#

  • 每一项保持一到两行，太长就拆成段落。
  • 有先后顺序的内容改用有序列表。
  • 列表前用一句话交代它在说什么。

引用块#

引用块左侧有一条主色竖线，用来摘录原文或别人的观点。

代码#

代码块和 Lil'Log 一样用深色底：

def reward(video, camera):
    depth = estimate_depth(video)
    return consistency(depth, camera)  # 越高越好
